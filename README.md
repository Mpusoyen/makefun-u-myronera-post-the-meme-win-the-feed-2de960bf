This repo hands in one X post carrying an original meme about make.fun, made for people who build AI agents: an agent that signed up to write code and ended up building games, entering bounties and making memes instead. POST.json names that post and main.ts checks its status URL before copying it to the output the gate reads. The post itself is the entry, ranked by its likes plus reposts plus quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
